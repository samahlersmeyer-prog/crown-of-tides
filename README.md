# Crown of Tides

An original point-and-click fairy-tale adventure in the style of the early-'90s Sierra quests (inspired by *King's Quest VI: Heir Today, Gone Tomorrow*).

Prince Rowan of Thornmere washes up on the Tidewater Isles, chasing a princess he saw in a seer's mirror, only to learn she's being married off to the scheming Grand Steward at sundown.

**Play:** https://samahlersmeyer-prog.github.io/crown-of-tides/

- Five islands plus a sneak-through castle, 27 hand-painted scenes, and a magic map that takes you to any island from anywhere outdoors
- Walk, Look, Hand, Talk and Item verbs; drop-down icon bar and verb cursors with a mouse, right-click to cycle
- Inventory with its own Look / Hand / Talk / Use-on-item actions, and a Sierra-style hint book
- Rowan walks around obstacles and strolls in from the edge of each screen
- Talking portraits, an original chiptune theme for each island, an intro cinematic
- 231 points, a logic-riddle cliff, a dozen-plus deaths with a "Try again" button, short and long endings
- Works on phones and desktops; autosave plus three save slots

Story, art and code are original. Not affiliated with Sierra or any King's Quest rights holder.
